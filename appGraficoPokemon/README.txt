APP GRÁFICO - POKÉMON
=====================

1) Importe o arquivo pokemon.sql no HeidiSQL/phpMyAdmin/MySQL.
2) Crie a pasta:
   AulaPamII/pokemon/
   dentro do htdocs (XAMPP) ou www (Laragon).
3) Coloque geragraficos.php nessa pasta.
4) No App.js, confira a constante API_URL.
   Se o IP do computador mudou, troque 10.67.57.174 pelo IP atual.
5) Inicie Apache e MySQL.
6) Execute o app Expo normalmente.

Dependência usada no projeto:
react-native-chart-kit

Observação:
Os votos são dados fictícios criados somente para a atividade escolar.
